# Visual Specification

> 本页是后续 DEMO 与 Interactive HTML Atlas 的生成输入；所有视觉必须遵循 [[../../../X1 Organizational World & UX Shell/World Visual Bible|World Visual Bible]] 与 WORLD-02。

- **Scene / Space**：赏金酒馆与多条出发路线。
- **Objects**：一张 Task Card、多份 Claim、多个 Execution、HAU 与唯一 Human owner 标记。
- **Semantic Mapping**：Task 是共享契约；每份领取凭证是一场 Execution。
- **Behavior / State**：同一 Task 可同时产生多条路线和独立状态。
- **禁止误读**：Claim 不排他；Capability 不加锁；Task 状态不代替 Execution 状态。
