# Visual Specification

> 本页是后续 DEMO 与 Interactive HTML Atlas 的生成输入；所有视觉必须遵循 [[../../../X1 Organizational World & UX Shell/World Visual Bible|World Visual Bible]] 与 WORLD-02。

- **Scene / Space**：史册室与道路网络台。
- **Objects**：事件卷轴、对象节点、依赖道路、Change Set 光圈。
- **Semantic Mapping**：时间轴只映射 Event Graph；道路只映射 material dependency。
- **Behavior / State**：普通 Event 轻量入史；Material Change 才沿受影响道路传播。
- **禁止误读**：关联不等于依赖；不得显示私人推理或把每个事件画成警报。
