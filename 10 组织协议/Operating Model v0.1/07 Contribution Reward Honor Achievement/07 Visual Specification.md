# Visual Specification

> 本页是后续 DEMO 与 Interactive HTML Atlas 的生成输入；所有视觉必须遵循 [[../../../X1 Organizational World & UX Shell/World Visual Bible|World Visual Bible]] 与 WORLD-02。

- **Scene / Space**：匿名价值评议室、徽章墙与功勋殿。
- **Objects**：匿名 Contribution Event、Evidence、Scarcity/Saturation、Reward Pool、Badge、少量 Honor Story。
- **Semantic Mapping**：徽章记录经历；Honor 纪念 Event；两者都不授予 Authority。
- **Behavior / State**：评议后才恢复归属；饱和改变价值语境但不抹除贡献。
- **禁止误读**：不得出现人物总榜、赢家通吃或固定 Honor 配额。
