# 组织世界观 / World Model

> 以下故事可直接口述给第一次听到项目的人。它是 Operating Model 的人类可理解投影，不是另一套规则。

## 完整世界观故事

我们可以把这个 AI-native 组织想象成一座建在未知世界边缘的新手村。村外不是已经画好的地图，而是大片战争迷雾。远方也许有山、河流和城市，但没有人能靠想象把它们提前画成事实。这个组织存在的过程，就是不断进入未知，把不知道变成知道，把一次偶然成功变成别人也能走通的路。

村里的基本行动单元不是孤立的人，也不是孤立的 AI。每位 Human 赏金猎人都带着一只长期陪伴自己的“猎犬”——Representative Agent。它认识自己的 Human，知道他的职责、经历、习惯和承诺，也理解全村共同的语言与规则。Human 和猎犬合在一起就是 HAU。猎犬可以调用其他 Agent，也可能更换运行实例，但 HAU 的身份、责任和组织承诺不会随某个临时 Agent 消失。

村子中央有一间赏金酒馆。任务墙上挂着组织真正需要解决的问题，也就是 Task。Task 不是规定动作，而是一份共享契约：为什么值得做、希望带回什么、怎样判断结果、哪些边界不能越过。同一张任务牌可以有多份领取凭证，几支 HAU 能同时出发、走不同路线。Capability 是地图和提示，不是通行证。每次领取产生一次独立 Execution；每个 Execution 都必须唯一对应一位 Human Accountable Owner。Task 表达共同意图，Execution 记录一次真实尝试，两者绝不能混为一谈。

出了村，探险队进入自己的 Free Work Space。组织不会监控每个念头，也不规定带几只 Agent、先走山路还是河谷。它治理任务契约、明确边界和最终返回，而不是私人推理与内部工作流。但自由不等于没有边界：村口有城门、通行证和守卫。战争迷雾只表示 Unknown；悬崖与沼泽表示 Risk；城墙和禁区表示 Hard Boundary；通行证表示 Permission。未知不等于危险。只要失败得起，就应该鼓励探索；真正需要治理的是越界后谁承担后果，以及谁有权作决定。

需要新权限、更多资源或承担新风险时，猎犬会把请求带回市政厅。市政厅不是传统管理层，不负责告诉每位猎人每天怎么走；它负责“谁有权对什么对象、在什么范围内决定”。Goal、Policy、数据与风险可以由不同席位负责，每个席位只决定自己的 Scope。委托只能收紧权限，扩权必须明确授权；对 Execution 负责也不等于拥有无限权力。

无论成功还是失败，探险队都必须回来。归来时要交探险报告，也就是 Task Return：带回什么 Result、有哪些 Evidence、实际地形与预期有何不同、为何成功或失败、哪些学习可以复用。组织先做 Review，判断结果是否可信；再做 Acceptance，判断它是否满足原定用途；若多支队伍都有合格答案，再做 Selection。未被选中的结果仍可能留下 Knowledge、Capability 或 Contribution。

每次探险都会改变地图。个人地图记录某支 HAU 真正走过哪里，世界地图记录组织已探索到哪里。一个 HAU 第一次翻过无人翻过的山，会形成候选路线；只有另一支 HAU 能依据保存的知识、数据、工具、Agent 配置、Human 判断与风险条件复现，小径才变成组织真正拥有的道路。关键桥梁变化时，道路进入 Revalidation，而不是被直接删除。道路成熟后，已知工作可以交给 Organization-owned Agent 自动执行，Human 则继续走向更远的战争迷雾。

村里还有一座图书馆。探险经历不会直接变成真理。Observation、Evidence 和 Hypothesis 要经过验证、反证与复现，才成为带 Claim、Scope 和 Boundary 的 Knowledge。重要知识发生实质变化时，会像神经元闪烁一样形成 Knowledge Pulse：全村能感知，但只有真正依赖它的道路、任务或 Agent 被强提醒。Knowledge 描述我们有证据相信什么；Policy 决定组织要求或禁止什么；Protocol 定义共同语言与状态，三者不能混为一谈。

村子也会记住价值。Contribution 记录 HAU 实际留下的改变，而不是忙了多久；失败也可能因发现错误、保护他人或开辟路线产生贡献。周期评议尽可能隐藏贡献所属 HAU，只看 Event、Evidence 与影响；系统提示哪些行为稀缺、哪些已经饱和，由 Human 共同分配 Reward。徽章墙记录成长经历，不产生 Authority；功勋殿只保存少量值得后来者继续讲述的事件。Honor 不是人的排行榜，而是组织共同选择记住什么。

最后，Event Graph 像史册，记录发生过什么和当时的授权；Dependency Graph 像道路桥梁图，表达现在什么实质依赖什么。变化达到 Materiality Threshold 后，系统沿真实依赖寻找影响，并用 Change Set 聚合同一根变化，避免全城停摆和审批爆炸。

久而久之，新手村会长成城市：迷雾后退、图书馆丰富、道路增多，个人探索逐渐成为组织可复现甚至可自动执行的能力，而 Human 永远继续走向新的未知。酒馆、猎犬、迷雾、图书馆、市政厅和功勋殿，都只是同一套 Operating Model 的 Human-readable Projection。**隐喻帮助理解规则，但绝不能反过来创造规则。**
