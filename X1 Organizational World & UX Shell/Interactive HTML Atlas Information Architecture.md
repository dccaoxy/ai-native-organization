# Interactive HTML Atlas — Information Architecture

> 当前交付仅冻结信息架构与下钻语义，不以草率 HTML 代替文档基线。

## Global Panorama

首页以城市全景呈现 00–08 与 X1；任何世界对象都可以下钻至：`Module → L2 Principle → L3 Mechanism → Organizational Object → Event History / Dependencies / Evidence / Authority`。

## Five Views

| View | 核心问题 | 主要图层 |
|---|---|---|
| World | Human 如何理解并进入组织？ | 城市空间、任务、地图、图书馆、功勋殿 |
| Architecture | 系统由什么构成并如何连接？ | Objects、Events、Dependencies、L3 mechanisms |
| Knowledge | 我们知道什么、为何相信、适用哪里？ | Claim、Evidence、Scope、Challenge、Pulse |
| Authority | 谁能决定什么，来源和范围是什么？ | Goal/Policy/Data/Risk Authority、Permission、Audit |
| Value | 什么改变了组织，如何评价与记忆？ | Contribution、Impact、Reward、Badge、Honor |

## Module Drill-down Contract

每个模块页固定提供：Purpose、Principles、Mental Model、Core Model/Specification、Cross-module Connections、Panorama Topology、Visual Specification；并显示 Frozen/Tunable/Experimental 与 M0/M1/M2 标签。

## Cross-view Navigation

- 选择一个 Execution：World 显示探险，Architecture 显示 Task/Owner/Event，Knowledge 显示使用与产出，Authority 显示 Runtime Envelope，Value 显示 Contribution。
- 选择一个 Knowledge Change：World 显示 Pulse，Architecture 显示 Event/Dependency/Change Set，Authority 显示 Policy 决策，Value 显示 Protection/Learning impact。
- 视角切换保持同一 object id 与时间点，避免切换成另一套现实。

## Prototype Acceptance

原型必须通过 X1 两条体验路径；能证明 Task≠Execution、唯一 Human owner、Unknown≠Risk≠Boundary、Review≠Acceptance≠Selection、Knowledge≠Policy≠Protocol；任何演示数据必须明确标为 synthetic fixture。
