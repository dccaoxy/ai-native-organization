# World Visual Bible / 世界视觉设定集

> 用途：让后续 Work 能直接生成一致的 DEMO 图片与交互原型。最高约束是 **WORLD-02：Metaphor explains rules; it does not create rules.**

## 整体视觉世界

- 一座位于未知边缘、随真实组织行为持续扩张的新手村/城市；不是中世纪游戏皮肤，也不是企业驾驶舱换背景。
- 气质应同时包含探索感、可理解的公共秩序与 AI-native 的动态信息层。世界可以温暖、有生命，但不能靠伪造数据制造繁荣。
- 视觉层级：地理空间负责直觉；信息叠层负责精确状态；任何装饰不得覆盖责任、边界、证据和状态。

## Human / Representative Agent / HAU

- Human 是赏金猎人；Representative Agent 是长期同行的猎犬；二者共同作为 HAU 出现。
- 猎犬应表现为有能动性的认知伙伴与组织接口，不是低智能宠物，也不是凌驾 Human 的主人。
- 同一 Human 只有一个活跃组织代表接口；可通过轻量徽记表现 HAU identity、Execution owner 与 runtime health。

## 视觉语义词典

| 语义 | 推荐视觉 | 禁止混淆 |
|---|---|---|
| Unknown | 中性、可探索的雾与未绘制地形 | 红色危险、禁入警示 |
| Risk / Hazard | 悬崖、沼泽、风暴及风险等级叠层 | Hard Boundary |
| Hard Boundary | 清晰城墙、封锁线、不可穿越结构 | 普通未知或能力差距 |
| Permission | 有来源、范围、期限的通行证 | Capability/Badge |
| Knowledge | 有 Claim/Scope/Evidence 的书卷或知识节点 | Policy/SOP |
| Capability | 脚印、小径、经复现加固的道路 | 人物等级、权限 |
| Dependency | 桥梁、补给线、承重道路 | 仅仅“相关”的连线 |
| Event | 史册中的原子记录、时间印记 | 当前依赖状态 |
| Contribution | 匿名事件卡与可追溯 Impact | 工时/活动量 |
| Achievement | 可丰富出现的个人经历徽章 | Authority/Honor |
| Honor | 稀少、叙事化的事件纪念碑 | 人物排行榜 |

## 状态与运动语言

- 普通 Event：轻量时间印记；Material Change：沿真实依赖产生定向脉冲。
- Knowledge Pulse：全局可感知、局部强提醒；避免全屏红色警报。
- Candidate Capability：崎岖小径；Reproduced Capability：稳定道路；Revalidation Needed：桥梁检修标记，不是道路消失。
- Runtime：Active 使用稳定呼吸光；Degraded 使用琥珀色节律；Suspended 使用静止隔离态。
- Blind Valuation：身份遮蔽但 Evidence、Goal Impact、Downstream Impact 完整可见。

## 构图与信息层

- 鸟瞰用于理解模块关系；近景用于任务、返回与治理动作；地图叠层用于 Architecture/Knowledge/Authority/Value 视角。
- 每张图需附 `purpose / canonical objects / current states / allowed interactions / forbidden inference`，避免只有美术 Prompt。
- 文案优先采用真实对象名；世界隐喻作为副标题或空间名，确保 Agent 能从画面回到 Specification。

## 绝对禁止

- 为“好看”制造未发生的能力、Honor、地图或组织繁荣。
- 用角色等级、装备等级或徽章限制 Task Claim。
- 把 Unknown、Risk 与 Hard Boundary 统一画成红区。
- 把 Task 画成唯一胜者、把 Parallel Execution 画成淘汰赛。
- 把市政厅画成万能 Manager，或把 Agent 画成无 Human 责任的组织权力主体。
- 展示、推断或要求保存私人思维链。
