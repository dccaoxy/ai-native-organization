# DEMO 图片 Backlog

> 每项都必须从真实/明确的样例状态生成；没有数据时使用清楚标记的结构示例，不冒充真实组织数据。

## DEMO-01 新手村鸟瞰概念图

- **目的**：一眼说明组织如何从探索中增长。
- **必须出现**：酒馆、城门、地图室、图书馆、市政厅、徽章墙/功勋殿、村外迷雾与道路。
- **语义映射**：各空间严格映射 X1 Seed World Ontology；道路由 Capability 产生。
- **关键状态**：已知区、Unknown、Hazard、Hard Boundary 分开；一条新小径与一条成熟道路并存。
- **禁止推断**：城市面积不代表组织人数或等级。

## DEMO-02 赏金酒馆任务墙

- **目的**：展示 Task 是机会市场、Claim 产生 Execution。
- **必须出现**：Task Card、Primary Goal、Expected Result、Acceptance Criteria、Boundary、Capability/Terrain 提示、多份 Claim。
- **语义映射**：一张 Task Card 对多个独立 Execution；每个 Execution 显示唯一 Human Accountable Owner。
- **禁止推断**：Capability 不得变成锁；Claim 不得排他。

## DEMO-03 HAU 个人战争迷雾地图

- **目的**：展示成长是经历与 Terrain，不是等级。
- **必须出现**：Human+猎犬、已探索脚印、未知雾、风险提示、能力证据、可挑战任务。
- **语义映射**：个人地图只来自真实 Execution Evidence；Badge 作为经历旁注。
- **禁止推断**：未探索不等于不能去。

## DEMO-04 地图室 Organizational Capability Map

- **目的**：展示个人成功如何经复现成为组织道路。
- **必须出现**：Expected/Observed Terrain、Candidate 小径、Reproduction 印章、稳定道路、关键依赖桥、Revalidation 状态。
- **语义映射**：桥梁来自 Dependency Graph；道路成熟度来自可复现证据。
- **禁止推断**：路线存在不自动授权自动化。

## DEMO-05 图书馆 / Knowledge Pulse

- **目的**：展示 Experience→Hypothesis→Knowledge 及选择性传播。
- **必须出现**：报告、Evidence、Hypothesis Cloud、Knowledge Claim/Scope/Boundary、Pulse 与受影响依赖。
- **语义映射**：图书馆内容是 Knowledge，不是 Policy；强 Pulse 只沿 material dependency。
- **禁止推断**：单次报告不直接成为真理；全局可见不等于全员打断。

## DEMO-06 功勋殿 + 徽章墙

- **目的**：清楚分开 Achievement 与 Honor。
- **必须出现**：丰富的个人经历徽章、极少量事件故事碑、Event/Evidence/Impact 摘要。
- **语义映射**：Badge 属于 HAU 经历；Honor 纪念事件与文化价值。
- **禁止推断**：不出现人榜、Honor 配额或由徽章产生的 Authority。

## DEMO-07 市政厅 Governance 界面

- **目的**：展示决策权架构与 Change Set，而不是审批中心。
- **必须出现**：同一 Change Set、Goal/Policy/Data/Risk 不同 Authority 席位、各自 Scope、authority-at-the-time、自动响应与待决事项。
- **语义映射**：每席只决定其对象范围；Knowledge Change 只是 Policy Decision 的输入。
- **禁止推断**：责任不等于无限权力；Goal 修改不自动扩 Permission。
