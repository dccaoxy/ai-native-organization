| 术语 | 规范含义 |
|---|---|
| Task | 多个尝试共享的组织问题与契约；服务Active Goal。 |
| Execution | 执行单元的一次真实尝试；状态、Return与唯一Human责任人归于此。 |
| HAU | Human + Active Representative Agent的持久组织工作单元。 |
| Representative Agent | Human/HAU唯一Active组织代表接口，不等于所有私人Agent的管理者。 |
| Organizational Event | 统一事件模型中的事实变化；Audit等模块消费而非复制事实。 |
| Event Graph | 发生过什么及事件历史联系。 |
| Dependency Graph | 当前实质依赖；不是所有关联。 |
| Material Change | 足以改变有效Claim/Scope/Boundary/Decision/State的变化。 |
| Change Set | 相关实质事件的治理聚合，不替代事件。 |
| Review | Result可信吗。 |
| Acceptance | 可信Result是否满足当前用途，需授权。 |
| Selection | 多个合格Result中采用哪个。 |
| Knowledge | 基于Evidence、带Scope与Boundary的Claim。 |
| Policy | 当前允许、禁止、要求什么。 |
| Protocol | 共同语言、语义、状态表达与交互结构。 |
| Handover | Context Reconstruction，基于持久现实重建。 |
| Capability | 由Execution Evidence塑造的地形/能力关系，不是权限等级。 |
| Contribution | 可追溯的正向组织变化。 |
| Reward | 当前周期价值分配，不自动永久沿因果链分成。 |
| Honor | 共同保存的行为与价值记忆。 |
| Achievement | 成长经历和里程碑，不创造权限。 |
| Risk Authority | 跟随实际后果承担者及合法代表权。 |
| L1/L2/L3 | 本原则树分别为基础原则/模块原则/机制；旧Recovery或Intervention同名分级不是本树级别。 |
