## 全局主链

Human/HAU → Goal → Task Contract → Task Bus/Claim → Execution → Free Work Space → Task Return → Review → Acceptance → Result；并行合格Result再经Selection。Return/Result/Events输入Knowledge、Capability与Contribution；Knowledge/Capability回到Execution，Goal所需Gap派生新Task。

00 Reality为所有模块共享底座；05 Runtime与08 Governance横跨各模块。事件历史、当前依赖、认知传播、授权与流程不能用一种无标签箭头混画。

## 视角与导航

Organization → Module → Mechanism → Object/State/Event → Specification/Source。用缩放与下钻表达深度，不要求真正3D。Operating、Human/HAU、Knowledge、Authority、Value视角使用同一组节点，Architecture/World投影使用相同底层本体。赏金酒馆、图书馆、战争迷雾与Honor Hall是理解入口，不另造业务语义。

导航需提供返回总图、面包屑、跨模块跳转、来源与原则查看。选择一个对象时按关系类型高亮Goal、Execution、Knowledge、Capability、Contribution、Risk与Event，不把所有连接当Dependency。
