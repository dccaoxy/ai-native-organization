双循环总览

Operating Loop v0.2 · AI-Native 组织如何持续运行与学习
AI-Native 组织同时运行“工作闭环”和“知识形成闭环”。
执行闭环：Goal → Task → Work → Review → Acceptance → Result
学习闭环：Events → Attention → Hypothesis → Verification → Knowledge
Knowledge 通过 Behavior Change / Protocol OTA 改变下一轮工作
Goal→Task→Work→Result→Learning→Knowledge→Protocol OTA→New Work

Hypothesis Cloud 与 Evidence

Operating Loop v0.2 · AI-Native 组织如何持续运行与学习
AI 维护多个竞争解释，不因为一个合理故事就宣布找到原因。
Hypothesis Cloud 可收缩、扩展、分裂或合并
Evidence 相对于 Claim：Support / Contradict / Discriminate / Neutral
多个 Agent 重复同一来源，不构成独立 Evidence
结论影响越大，Evidence 门槛越高
Pattern→Hypothesis Cloud ⇄ Evidence
