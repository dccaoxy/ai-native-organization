# 网页测试门户：用户说明

新入口：http://127.0.0.1:8876 。当前由开发侧在本机运行，尚未发布到云端。

你不需要安装 Python、Node 或任何依赖，也不需要终端、控制密钥或测试身份编号。

1. 打开网页，填写账号、显示名和密码，点击“注册账号”；以后直接登录。
2. 在“创建目标与任务”中填写目标、成功标准和任务，选择审查/验收/最终选择的负责人，再发布任务。其他负责人需先注册自己的账号。
3. 到“Agent 注册与授权”，填写名称并生成完整 Agent 接入说明（会新建待授权注册），点击“复制完整接入说明”，交给具备 HTTP 能力的 Agent。基础权限已预选，你只需选择允许的任务并确认授权；高级选项可按需修改。它只代表你的账号。
4. 整段说明包含地址、凭据、接入确认、授权状态检查和执行步骤，无需另行教 Agent 调接口。页面会显示已确认连接；这不表示获得全部权限。已授权 Agent 可在卡片中“保存权限调整”，立即生效。当前 localhost 地址仅平台所在电脑可达，云端 Agent 需等待可访问的测试地址。没有外部 Agent 时，可直接使用网页里的“浏览器协议测试客户端”；它只验证接口，不调用模型、不完成真实业务任务。
5. 在“正式结果”中，由指定负责人分别审查、验收和选择结果。需要其他人处理时，由对方登录自己的账号，不能切换成对方身份。

这是共享测试组织，成员可见正式协作事实。请勿放入真实公司或敏感个人资料。账号认证不等于现实身份核验。目前没有邮箱验证、找回密码或模型托管。

旧 8877 控制台保留开发用途，不再作为普通用户入口。开发侧正在准备云端常驻服务候选包；正式推送/部署前另行确认，正式用户测试尚未开始。
