# PA01 — 普通用户网页入口

用户于 2026-09-11 授权：继续开发到普通用户可在网页注册、登录和接入 Agent，不需安装依赖或执行命令，再进行正式试用。本轮是该目标的本地可运行交付，不是线上部署或真人实验。

## S01 依赖与输入

依赖 UX02 已本地 PASS。输入 organization/specs/tests、冻结 Baseline 与 PA01 规格；输出账号门户、会话/账号存储、网页目标任务表单、所属 Agent 创建授权、浏览器协议客户端、运行服务模板及验收证据。

独立数据目录 `.autodev/portal`，不导入旧测试 Human，不共用 operator key，不暴露 `/control` 或允许从浏览器指定 actor。账号对应唯一服务端 Human；是测试账号认证，不宣称现实身份认证。组织事件仍明确 simulation=true。

## 可验收行为

1. 普通用户网页注册账号/密码/显示名，登录和退出；刷新与服务重启继续已保存的账号及有效会话。
2. 服务端使用 scrypt 密码哈希、随机盐、会话 token 哈希与过期、HttpOnly/SameSite Cookie、同源/CSRF 校验、登录注册限速。HTTPS 部署时启用 Secure；没有公开 HTTP 监听。
3. 网页创建目标、任务、指定三种责任人、发布任务。用户不填写 Human/HAU 编号，不任意切换账号。
4. 网页生成独立 Agent 凭据，只有所属 Human 可批准，明确选择任务和操作；凭据只显示一次。现有 API 的权限、幂等和撤销语义保持不变。
5. 网页提供可复制连接配置和 Agent 协议说明；自带显式标识的浏览器协议测试客户端，不调用模型，不能冒充真实业务成果。
6. 实际浏览器从空库创建两个账号，经授权客户端提交后，由指定账号分别 Review/Acceptance/Selection；重试不增事件，窄屏可使用，源码摘要绑定报告。
7. 完整回归、独立确定性 Review、原则 Audit/冻结完整性通过后形成 commit/tag/artifact。

## 服务与边界

本机新门户默认 8876；旧 8877 合成控制台保留。由开发侧启动服务，普通用户只访问网页。服务器仍需 Python 标准库；Node/Playwright 仅开发测试依赖。常驻服务模板 `deploy/test-portal` 含独立目录/账户/端口与 systemd 自动重启候选配置，未部署。启动后台本地进程不承诺关机运行或 Windows 开机自启。

当前为单一共享测试组织，注册页明确披露成员可见组织事实；不提供生产多租户隔离、邮箱验证、找回密码、真实模型托管或真实公司接入。不要把注册成功等同真人实验验证。外部 Agent 需要支持 HTTP 协议，Human 不必运行本地脚本。

正式 Git push、云端安装/服务启动、域名/TLS/反向代理入口变更须具体方案与用户确认，不自动修改 AEGPC.CN。当前只完成可审查候选包。本地开发和自动化合成验收无需再次确认。

## 失败与恢复

repair budget=1；工程失败进入 BLOCKED_ENGINEERING，按真实回执修复；不伪造通过。若涉及冻结语义、真人 Purpose/Authority/Risk 则 HUMAN_DECISION_REQUIRED。账号预留后、事件前中断可在登录时幂等补全 HumanRegistered。会话和注册归属落 SQLite，不依赖聊天或浏览器内存；未保存的一次性 Agent 凭据不可事后读回。

回滚停止本独立门户并使用旧代码 checkout；旧实验室不受影响。数据库需正确 SQLite backup，勿覆盖或混合账号库。不得 force-push、覆盖 tag 或销毁历史。
