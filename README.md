# AI-Native Organization

一个约60名跨部门新人、为期一年的实验组织：以Human/HAU、Goal、Task/Execution、Knowledge和Capability探索效率、创新、学习与组织智能。

当前设计权威：[Operating Model v0.1 Final Design Baseline](00%20%E9%A1%B9%E7%9B%AE%E6%80%BB%E8%A7%88/Operating%20Model%20v0.1%20Final%20Design%20Baseline.md)。已纳入最终逐模块收敛、Pass 2、11+1 L1、101条L2、79项L3机制、冻结分类、MVO与8项实验。

横切体验权威：[X1 Organizational World & UX Shell](X1%20Organizational%20World%20%26%20UX%20Shell/X1%20Organizational%20World%20%26%20UX%20Shell.md)。X1 是 Operating Model 的多视角投影，不改变 00–08 的规则。

## 版本与载体

Obsidian项目为日常文档载体，本Git仓库是项目发布与版本记录副本；长期记忆仓库不是本项目源码/原文仓库。更新日期2026-09-08。历史报告和原始讨论保留当时状态，当前入口不以旧“待设计”标记覆盖最终基线。

现有PNG/HTML为历史视觉版本，未完整表达最终Task/Execution及Reality Layer；X1 已建立视觉生成语义规格，但 Interactive HTML Atlas 与 DEMO 图片尚未实现。核心设计冻结不代表参数已定、实验已验证或M0已经上线。
